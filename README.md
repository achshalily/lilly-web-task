# Lily – Responsive React Website

Lily is a responsive 4-page company website built using **React.js** and **React Router**. The project demonstrates a clean, modern user interface with reusable components and responsive design principles.

## Features

- Responsive navigation bar
- Hero banner with welcome section
- Features section
- About page with:
  - Company Introduction
  - Mission
  - Vision
  - Why Choose Us
- Services page with service cards
- Contact page with:
  - Contact form
  - Company information
- Reusable Navbar and Footer components
- Mobile-friendly responsive layout
- Simple hover effects and smooth user interactions

## Technologies Used

- React.js
- React Router DOM
- CSS3
- Vite

## Getting Started

Clone the repository and install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
